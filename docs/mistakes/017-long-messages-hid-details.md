# 017 · Long messages hid important details

- **Date:** 2026-11-11
- **Area:** communication

## What happened
The user said that long paragraphs make them miss useful details, and that missed details have caused problems in the build. They asked for precise answers that still keep everything important.

## Why
Explanations, decisions and the steps the user had to take were mixed together in long blocks of text, so the actions were easy to miss.

## Rule
Write short, structured messages: a one-line summary, then numbered steps or short bullets, with the user's own actions in bold. Never drop something important to save space; put it in its own line instead.

## Where
Every reply to the user, especially setup steps, decisions and anything they must do.
