# 006 · Full dashboard on an empty workspace

- **Removed:** 2026-11-10 (hidden until there is content)
- **Requested by:** the agent, as part of the clean start the user asked for

## What it was
Home always showed the stat tiles, Pinned, Continue writing, Up next and the posting-activity heatmap.

## Why it was removed
On a new, empty workspace that meant rows of zeros and empty boxes on the first screen.

## What replaced it
Until the first document exists, Home shows the first-space form (if needed), the templates and "How it fits together". The full dashboard appears automatically once there is a document.

## Bringing it back
It already comes back by itself once there is content; don't show it on an empty workspace.
