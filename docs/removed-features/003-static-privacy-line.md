# 003 · "Private · stored on this device" sidebar line

- **Removed:** 2026-11-09
- **Requested by:** the agent, after the user said the goal is to keep posts saved

## What it was
A static line at the bottom of the sidebar saying the data is private and stored on this device.

## Why it was removed
It was reassuring but gave a false sense of safety: browser storage alone can be wiped.

## What replaced it
A live backup status line ("Backed up 3m ago", "Not backed up yet", "Reconnect backup folder") that opens Settings or reconnects the backup folder.

## Bringing it back
Not needed; the backup line answers the same question with real information.
